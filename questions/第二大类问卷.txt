每题采用5级李克特量表：1=完全不符合；2=不太符合；3=一般；4=比较符合；5=完全符合01 科学型（科学研究人员）1. 我喜欢探索未知、提出假设、通过实验验证规律。2. 我擅长逻辑推理、数据分析与理论推导。3. 我能长期专注、耐心钻研，不畏惧复杂问题。4. 我重视严谨性、可重复性，追求客观准确的结论。5. 我愿意持续学习前沿知识，保持学术好奇心。02 工程型（工程技术人员）1. 我喜欢动手设计、解决实际工程问题。2. 我擅长使用工具、设备与技术方案完成项目。3. 我重视效率、安全、成本与工程规范。4. 我能在压力下稳定执行，保证工程质量。5. 我愿意学习新技术、新工艺，适应行业更新。03 农业型（农业技术人员）1. 我喜欢接触自然、动植物、土地与农业生产。2. 我擅长观察作物生长、养殖规律并优化管理。3. 我能适应户外、田间、季节性工作。4. 我重视生态、安全、产量与品质。5. 我愿意学习农业技术、育种、植保等知识。04 航空航海型（飞机和船舶技术人员） 1. 我对飞行器、船舶结构、航行系统有浓厚兴趣。2. 我擅长精密操作、设备维护与安全检查。3. 我做事严谨细致，重视安全规范与流程。4. 我能适应高空、海上、复杂环境下的工作。5. 我具备冷静判断力，能应对突发技术故障。 05 医疗型（卫生专业技术人员） 1. 我愿意帮助他人、关心健康、提供医疗服务。2. 我擅长观察症状、分析病情、执行诊疗流程。3. 我有耐心、细心、同理心，能安抚患者情绪。4. 我重视医学规范、无菌操作与安全用药。5. 我愿意持续学习医学知识，提升专业能力。 06 经济型（经济和金融专业人员） 1. 我对市场、数据、经济规律有浓厚兴趣。2. 我擅长数据分析、风险评估与策略制定。3. 我重视逻辑、理性、客观判断。4. 我能在压力下做决策，保持冷静。5. 我愿意学习经济、金融、政策相关知识。07 法律社会型（监察、法律、社会和宗教专业人员） 1. 我关注公平正义、规则秩序与社会问题。2. 我擅长逻辑分析、证据梳理、文书撰写。3. 我重视原则、程序、规范与责任。4. 我能理性沟通、调解矛盾、处理复杂关系。5. 我愿意学习法律、政策、社会治理知识。 08 教师型（教学人员） 1. 我喜欢分享知识、引导他人学习与成长。2. 我擅长表达、讲解、组织课堂与活动。3. 我有耐心、责任心，愿意陪伴学生进步。4. 我重视教育规律、学习方法与育人目标。5. 我愿意持续学习教育理念与学科知识。 09 文体型（文学艺术、体育专业人员） 1. 我喜欢创作、表演、运动或艺术表达。2. 我具备审美、创意、表现力或运动天赋。3. 我能坚持训练、练习，追求专业水平。4. 我重视细节、风格、表现力与专业标准。5. 我愿意在舞台、赛场或创作中展现自我。 10 传播型（新闻出版、文化专业人员） 1. 我喜欢收集信息、表达观点、传播内容。2. 我擅长写作、采访、编辑、策划与表达。3. 我重视真实、客观、逻辑与传播效果。4. 我能适应信息更新快、节奏紧张的工作。5. 我愿意学习传播、媒体、文化相关知识。
