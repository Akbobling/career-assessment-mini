---

## 📋 项目简介

**职途探索** 是基于微信小程序开发的职业规划服务平台，采用 **T-Design 组件库** 构建界面，**微信云开发** 提供后端支持。平台涵盖职业测评、薪资爆料、个人中心三大核心模块，帮助学生了解自身职业适配度，获取真实薪资信息，做出更明智的职业决策。

---

## 🏗️ 技术架构

| 层级 | 技术选型 | 说明 |
|------|---------|------|
| 前端框架 | 微信小程序原生框架 | 轻量高效，契合微信生态 |
| UI 组件库 | T-Design 小程序版 | 统一设计规范，提升开发效率 |
| 后端服务 | 微信云开发 CloudBase | 免运维，集成数据库、存储、云函数 |
| 数据存储 | 云数据库 + 本地缓存 | 双通道同步，保障数据可靠性 |
| 可视化 | 自定义柱状图 | 测评结果直观展示 |

---

## 📱 功能模块

### 核心测评（3 页完成）
- **测评首页** — 大类/中类职业测评入口，状态管理（已完成/未完成）
- **测评问卷** — 进度条展示，选项交互，支持多维度评估
- **结果展示** — 柱状图可视化对比，适配度排名清晰呈现

### 薪资爆料（2 页完成，2 页开发中）
- **薪资列表** — 校内爆料 / 广场双模式切换，支持多维筛选
- **发布爆料** — 表单涵盖类型、行业、公司、岗位、地区等字段
- **薪资详情** — 爆料内容深度浏览（开发中）
- **我的爆料** — 个人发布管理（开发中）

### 用户系统（3 页完成，1 页开发中）
- **个人中心** — 自定义 TabBar 导航，功能聚合入口
- **资料完善** — 强制引导流程，确保信息完整度
- **信息编辑** — 云端同步，多端数据一致
- **编辑资料页** — 精细化信息管理（开发中）

### 待开发功能
- 小类职业选择
